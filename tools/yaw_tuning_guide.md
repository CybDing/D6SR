# Yaw轴双环PID调节指南

## 🎯 调节目标
从零开始调节Yaw轴的双环级联PID控制器，使其能够稳定保持目标角度。

## 📐 系统架构
- **外环(位置环)**: 角度误差 → 速度目标 (°/s)
- **内环(速度环)**: 速度误差 → PWM增量
- **电机**: M0(负向), M1(正向), 基准PWM=1550

## 🔧 调节步骤

### 阶段1: 内环速度环调节 (重点!)

**目标**: 让速度环能够准确、稳定地跟踪目标速度，无超调、无震荡

#### 1.1 准备工作
```bash
# 1. 编译并烧录代码
cd stm32/
make flash

# 2. 打开串口监控
make monitor
# 或使用: screen /dev/ttyUSB0 115200
```

#### 1.2 使能调试输出
在串口终端发送:
```
ZDEBUG:1      # 开启Yaw调试输出
ZSTAB:1       # 开启Yaw双环PID控制器
```

#### 1.3 内环Kp调节 (先只调Kp)

**初始参数**:
- inner_kp = 0.5 (从小开始)
- inner_ki = 0.0 (暂时关闭)
- inner_kd = 0.0 (暂时关闭)
- outer_kp = 0.0 (外环暂时关闭)
- outer_ki = 0.0
- outer_kd = 0.0

**测试方法**: 修改cascaded_pid.c，在cascaded_pid_step()函数中强制设置速度目标
```c
// 在cascaded_pid.c的cascaded_pid_step()函数中
// 找到"外环输出: 速度目标"这一行之后，添加:
ctrl->velocity_target = 30.0f;  // 强制设置30°/s的速度目标
```

**调节步骤**:
1. 设置 inner_kp = 0.5，编译烧录
2. 观察调试输出中的 `v_fb` (实际速度) 和 `vtgt` (目标速度=30)
3. 如果 v_fb 远小于 vtgt (比如只有10°/s)，说明Kp太小，增大到0.8
4. 继续增大Kp，直到速度能够接近目标值 (允许±5°/s误差)
5. 如果出现震荡，说明Kp过大，减小10%

**期望结果**: v_fb稳定在25-35°/s范围内，无明显震荡

**参考范围**: inner_kp = 0.5 ~ 1.5

---

#### 1.4 内环Ki调节 (消除稳态误差)

**当前状态**: Kp已调好，但可能存在稳态误差(比如目标30，实际稳定在26)

**调节步骤**:
1. 设置 inner_ki = 0.05，保持Kp不变
2. 观察 v_fb 是否更接近 vtgt
3. 如果稳态误差仍然存在，增大Ki到0.1
4. 如果出现震荡或超调，减小Ki
5. 最终使 v_fb 稳定在 vtgt±2°/s 范围内

**期望结果**: v_fb = 30±2°/s，无震荡，无超调

**参考范围**: inner_ki = 0.05 ~ 0.2

---

#### 1.5 内环Kd调节 (可选，抑制速度噪声)

**注意**: 速度环的Kd通常很小，因为速度本身已经是微分量

**调节步骤**:
1. 设置 inner_kd = 0.02
2. 观察PWM输出(M0/M1)是否更平滑
3. 如果速度响应变慢，减小Kd
4. 如果PWM抖动严重，可以增大Kd到0.05

**期望结果**: PWM输出平滑，速度跟踪稳定

**参考范围**: inner_kd = 0.02 ~ 0.08

---

#### 1.6 验证内环性能

**测试不同速度目标**:
```c
// 修改velocity_target测试不同值
ctrl->velocity_target = 10.0f;   // 测试小速度
ctrl->velocity_target = 30.0f;   // 测试中速度
ctrl->velocity_target = 50.0f;   // 测试大速度
ctrl->velocity_target = -30.0f;  // 测试反向
```

**检查指标**:
- 响应时间: 0.5-1秒内达到目标速度
- 超调量: < 10%
- 稳态误差: < 5%
- 无持续震荡

---

### 阶段2: 外环位置环调节

**前提**: 内环速度环已调好！

#### 2.1 移除速度强制设置

删除或注释掉之前添加的强制速度目标代码:
```c
// ctrl->velocity_target = 30.0f;  // 删除这行!!!
```

现在velocity_target由外环PID计算得出。

#### 2.2 外环Kp调节

**初始参数**:
- outer_kp = 1.0 (从中等值开始)
- outer_ki = 0.0
- outer_kd = 0.0
- 保持内环参数不变

**测试方法**: 设置目标角度
```bash
# 在串口发送 (假设当前角度在0°附近)
STABLE:yaw:90    # 设置目标角度为90°
```

或者修改代码设置:
```c
// 在main.c的yaw_control_task()开始时添加:
cascaded_pid_set_target_angle(&g_yaw_cascaded_pid, 90.0f);
```

**调节步骤**:
1. 设置 outer_kp = 1.0
2. 观察调试输出的 `ang` (当前角度) 和 `tgt` (目标角度90)
3. 观察收敛速度:
   - 如果收敛太慢(>5秒)，增大Kp到1.5
   - 如果震荡明显，减小Kp到0.7
4. 最终使角度能在2-3秒内到达目标±10°范围

**期望结果**: 角度在2-3秒内接近目标，允许轻微震荡

**参考范围**: outer_kp = 0.8 ~ 2.0

---

#### 2.3 外环Kd调节 (抑制震荡)

**当前状态**: Kp调好后，可能出现小幅度震荡

**调节步骤**:
1. 设置 outer_kd = outer_kp / 10 (经验公式)
   - 比如 outer_kp=1.5，则 outer_kd=0.15
2. 观察震荡是否减小
3. 如果震荡仍然明显，增大Kd
4. 如果响应变慢，减小Kd

**期望结果**: 震荡幅度减小，快速收敛到目标

**参考范围**: outer_kd = 0.1 ~ 0.3

---

#### 2.4 外环Ki调节 (消除静差)

**当前状态**: 角度可能稳定在88°而不是90°(静差2°)

**调节步骤**:
1. 设置 outer_ki = 0.05
2. 观察 aerr (角度误差) 是否逐渐减小到0
3. 如果静差消除太慢，增大Ki到0.08
4. 如果出现积分饱和(突然大幅震荡)，减小Ki

**注意**:
- 死区设置为3°,所以误差<3°时积分会衰减
- 可以调整outer_deadband参数改变死区大小

**期望结果**: 最终稳定在目标角度±2°范围内

**参考范围**: outer_ki = 0.02 ~ 0.1

---

### 阶段3: 综合测试

#### 3.1 大角度测试
```bash
STABLE:yaw:0      # 回到0°
STABLE:yaw:180    # 转到180°
STABLE:yaw:270    # 转到270°
STABLE:yaw:0      # 回到0°
```

#### 3.2 小角度微调测试

```bash
STABLE:yaw:15
STABLE:yaw:20
```

#### 3.3 抗干扰测试
- 手动转动机器人内部机构
- 观察是否能快速恢复到目标角度

## 📊 调试输出解读

```
Yaw-Cascade: ang=45.2, tgt=90.0, aerr=44.8, v_fb=25.3, vtgt=44.8, verr=19.5, delta=15, M0=1535, M1=1565
```

各字段含义:
- `ang`: 当前角度 (45.2°)
- `tgt`: 目标角度 (90.0°)
- `aerr`: 角度误差 (44.8°)
- `v_fb`: 当前角速度 (25.3°/s)
- `vtgt`: 外环输出的速度目标 (44.8°/s)
- `verr`: 速度误差 (19.5°/s)
- `delta`: 内环输出的PWM增量 (15)
- `M0/M1`: 两个电机的实际PWM值

## 🛠️ 参数保存

调节完成后，将参数写入 [motor_calibration.c](stm32/motor_calibration.c:116-137):

```c
const CascadedPIDConfig YAW_CASCADED_PID_CONFIG = {
    // 外环 (位置环)
    .outer_kp = 1.5f,           // 你调节的值
    .outer_ki = 0.05f,          // 你调节的值
    .outer_kd = 0.15f,          // 你调节的值
    .outer_max_output = 60.0f,  // 速度上限
    .outer_deadband = 3.0f,     // 死区

    // 内环 (速度环)
    .inner_kp = 0.8f,           // 你调节的值
    .inner_ki = 0.1f,           // 你调节的值
    .inner_kd = 0.05f,          // 你调节的值
    .inner_max_output = 100.0f, // PWM增量上限

    // 其他参数保持不变
    .dt = 0.02f,
    .base_pwm_neg = 1550,
    .base_pwm_pos = 1550,
    .delta_sign_neg = -1,
    .delta_sign_pos = +1,
    .pwm_range = 150,
};
```

## ⚠️ 常见问题

### Q1: 速度震荡剧烈
- 检查inner_kp是否过大
- 检查PWM_SLEW_RATE是否太小(cascaded_pid.c:24)

### Q2: 角度收敛太慢
- 增大outer_kp
- 检查outer_max_output是否太小(当前60°/s)
- 检查inner环是否调好

### Q3: 角度震荡不停
- 减小outer_kp
- 增大outer_kd
- 减小outer_ki

### Q4: 存在静差(比如目标90°,实际88°)
- 增大outer_ki
- 检查outer_deadband是否太大

### Q5: 调试输出看不到
- 确认发送了 `ZDEBUG:1`
- 检查串口波特率是否115200
- 检查DEBUG_OUTPUT_DIVIDER分频(cascaded_pid.c:33)

## 🎓 调节原理

**为什么先调内环?**
- 内环是外环的执行器
- 如果内环不稳定,外环无法正常工作
- 就像汽车方向盘坏了,再好的导航也没用

**Kp/Ki/Kd的作用**
- Kp: 响应速度 (误差越大,控制量越大)
- Ki: 消除静差 (累积误差,最终消除偏差)
- Kd: 抑制震荡 (预测趋势,提前减速)

**双环PID的优势**
- 分层控制,各司其职
- 内环保证执行力,外环保证准确性
- 大角度调整时更平滑(不会突然猛转)
